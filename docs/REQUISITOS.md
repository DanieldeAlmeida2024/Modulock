# Requisitos

RF-01 Permitir cadastrar credenciais de administrador fora do código versionado.
RF-02 Autenticar sessão web por identificador aleatório válido.
RF-03 Liberar operações administrativas apenas com sessão válida.
RF-04 Acionar relé somente mediante mecanismo de autorização confiável.
RNF-01 Falhar de forma segura em ausência de configuração e Wi-Fi.
RNF-02 Desabilitar controles Bluetooth sem autenticação.
RNF-03 Não registrar dados de cartões, senhas ou identificadores de sessão.
RNF-04 Executar testes no hardware antes de implantação.
